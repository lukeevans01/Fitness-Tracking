# Muscle taxonomy

Canonical muscle group names used by the coaching system. Gemini uses these labels to detect overlap, flag overload, and schedule recovery.

## Primary groups

| Group | Sub-muscles |
|---|---|
| quads | rectus femoris, vastus lateralis, vastus medialis, vastus intermedius |
| hamstrings | biceps femoris, semitendinosus, semimembranosus |
| glutes | gluteus maximus, gluteus medius, gluteus minimus |
| calves | gastrocnemius, soleus |
| chest | pectoralis major, pectoralis minor |
| back | latissimus dorsi, rhomboids, mid-trapezius, lower trapezius |
| upper back / traps | upper trapezius, rear deltoid |
| shoulders | anterior deltoid, lateral deltoid, posterior deltoid |
| biceps | biceps brachii, brachialis |
| triceps | triceps brachii (long, lateral, medial heads) |
| core | rectus abdominis, obliques (internal + external), transverse abdominis |
| hip flexors | iliopsoas, rectus femoris |
| adductors | adductor longus/brevis/magnus, gracilis |

## Running muscle load

All runs load calves, quads, hamstrings, glutes, and hip flexors. Recovery priority after long runs: calves + hamstrings (highest load). Strength sessions targeting these groups should not follow a long run within 24h.
